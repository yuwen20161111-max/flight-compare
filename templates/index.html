機票比價系統

搜尋全球航班，找到最便宜的機票

首次使用 - 設定 API 金鑰（只需一次！）

本系統使用 SerpApi 搜尋 Google Flights 航班資料。
1. 前往 serpapi.com/users/sign_up 免費註冊
2. 註冊後到 serpapi.com/manage-api-key 複製你的 API Key
3. 貼到下方，按「儲存」就好了（每月免費 100 次搜尋）

只要告訴我「去哪裡」和「預算多少」，我會自動掃未來 2 個月的航班，幫你找到最便宜的來回機票！
* 系統會自動在你選的範圍內取樣搜尋，範圍越大需要越久（約 30~90 秒）
告訴我你的預算，我幫你看看這些錢能飛去哪裡！會搜尋 10 個精選目的地（亞洲、美洲、歐洲）。
* 搜尋 10 個目的地，約需 10~20 秒，每次消耗約 10 次 API 額度
